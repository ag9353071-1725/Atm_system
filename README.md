# 🏧 ATM System (Python OOP Project)

A simple Python-based ATM system built using Object-Oriented Programming (OOP) concepts.  
This project demonstrates **Encapsulation** and basic banking operations like balance check and PIN change.

---

## 🚀 Features

- 💰 Check account balance
- 🔐 Secure PIN management (Encapsulation)
- 🔄 Change PIN functionality
- 🧠 Simple OOP structure

---

## 🧠 Concepts Used

- Classes and Objects
- Constructors (`__init__`)
- Encapsulation (private variables using `__`)
- Methods
- Object creation
